Input GUP

Masukkan data pengajuan. Kolom jumlah terbayar dapat diisi atau diperbarui saat pembayaran dilakukan.

Input Data Kolektif Rekap GU

Kolom CSV: No GU, No SubGU, Nama Subsatker, Jumlah Renbut, PPN, PPH21, PPH22, PPH23, Jumlah Bersih, dan (opsional) Jumlah Terbayar. Baris pertama boleh berupa judul kolom.

Input Data Kolektif Detail GUP

Kolom CSV sama dengan rekap GU; data akan masuk ke tabel Detail GUP secara terpisah.
